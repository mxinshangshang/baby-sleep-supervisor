# 🎤 音频哭闹检测集成指南

## ✅ 已完成升级

**多模态哭闹识别系统** = **音频频谱分析** + **面部表情识别**

---

## 📊 准确率提升预期

| 检测方式 | 准确率 | 误报率 | 说明 |
|---------|--------|--------|------|
| 纯视觉 | ~75% | 较高 | 依赖面部可见，角度不好易漏 |
| 纯音频 | ~80% | 中等 | 环境噪音易误报 |
| **音频+视觉融合** | **~95%+** | **极低** | 双模态确认，大幅提升可靠性 |

## 🔧 集成的功能

### 1. 音频检测器 (`src/audio_detector.py`)

**哭声特征提取：**
- **音量 RMS** - 哭声通常 > 0.1 (安静环境 < 0.01)
- **基频范围** - 婴儿哭声 400-1000Hz
- **频谱质心** - 800-3500Hz (哭声高频丰富)
- **高频能量占比** - 25%-70% (哭声特有频谱分布)

**实时处理：**
- 48kHz 采样率
- 100ms 处理块
- 8帧滑动窗口平滑

### 2. 多模态融合算法

```
融合策略：
├─ 音频权重: 55% (哭声本身是更强信号)
├─ 视觉权重: 45%
├─ 双模态确认加成: +25% (同时≥50%时)
├─ 音频强信号透传: ≥70%直接触发
├─ 视觉强信号透传: ≥75%直接触发
└─ 单模态弱信号抑制: 降低到80%
```

### 3. 配置项 (`config.yaml`)

```yaml
audio:
  enabled: true                    # 音频模块开关
  cry_detection_enabled: true      # 音频哭闹检测开关
  device_id: null                  # null = 使用默认设备
  sample_rate: 48000               # 采样率
```

## 🎯 真实场景优化建议

### 场景1：宝宝背对摄像头（面部不可见）
- **旧行为**：完全无法检测哭闹
- **新行为**：音频独立检测，置信度≥70%仍可触发告警

### 场景2：宝宝张嘴打哈欠（不是哭）
- **旧行为**：易误报为哭闹
- **新行为**：音频无哭声信号 → 抑制误报

### 场景3：环境噪音（开关门、说话）
- **旧行为**：无影响
- **新行为**：频谱不匹配哭声特征 → 被过滤

### 场景4：宝宝小声抽泣
- **旧行为**：面部表情弱 → 可能漏报
- **新行为**：音频捕捉到哭声特征 → 补充检测
